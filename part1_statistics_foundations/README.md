# Part I -- Statistics Foundation for ML

Probability theory and mathematical statistics, before you touch any ML
model: sample spaces, random variables, moments, the standard discrete
and continuous distributions, convergence concepts, and estimation
(maximum likelihood and Bayesian). Based on the STAT4ML lectures by Omid
Safarzadeh, themselves built on Casella & Berger, *Statistical Inference*
(2002).
