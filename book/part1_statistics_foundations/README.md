# Part I -- Statistics Foundation for ML

Probability theory and mathematical statistics needed before touching any ML model: sample spaces, random variables, moments, the standard discrete and continuous distributions, convergence concepts, and estimation (MLE and Bayesian). Based on the STAT4ML slide deck by Omid Safarzadeh, itself built on Casella & Berger, *Statistical Inference* (2002).
